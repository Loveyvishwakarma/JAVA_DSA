# Java Input and Output Questions ☕

A collection of Java programs for practising **input and output operations** and understanding how Java programs interact with users.

This repository is part of my Java and Data Structures & Algorithms (DSA) learning journey. The programs focus on reading input, storing values in variables, performing basic operations, and displaying results.

## 📌 About This Repository

Input and output are fundamental parts of programming. Java provides tools such as `Scanner` and `System.out` to receive information from users and display results.

Through these exercises, I am practising how to:

- Read user input using `Scanner`.
- Work with different primitive data types.
- Declare and initialise variables.
- Perform arithmetic operations.
- Display formatted output.
- Understand basic Java program structure.

## ▶️ How to Run a Program

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the repository folder

```bash
cd inputOutput
```

### 3. Compile a Java file

For example:

```bash
javac ArithmeticOperations.java
```

### 4. Run the program

```bash
java ArithmeticOperations
```

Replace `ArithmeticOperations` with the class name of the program you want to execute.

**Note:** The Java filename and public class name must match. Make sure the Java JDK is installed and available in your terminal.
