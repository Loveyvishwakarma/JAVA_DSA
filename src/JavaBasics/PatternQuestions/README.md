# Java Pattern Questions ⭐

A collection of Java programs focused on learning and practising **pattern printing using loops and nested loops**.

This repository is part of my Java and Data Structures & Algorithms (DSA) preparation. It contains different star, number, and character patterns designed to improve my understanding of loops, conditional statements, and logical thinking.

## 📌 About This Repository

Pattern printing is an important beginner-level programming exercise that helps develop:

- Logical thinking and problem-solving skills.
- Understanding of `for` and `while` loops.
- Understanding of nested loops.
- Row and column-based logic.
- Conditional statements inside loops.
- Pattern recognition and mathematical thinking.

## ▶️ How to Run the Programs

### Step 1: Clone the Repository

```bash
git clone <your-repository-url>
```

### Step 2: Navigate to the Folder

```bash
cd patternQuestions
```

### Step 3: Compile a Java Program

For example:

```bash
javac Butterfly.java
```

### Step 4: Execute the Program

```bash
java Butterfly
```

Replace `Butterfly` with the appropriate class name to execute another pattern program.

**Note:** Make sure the Java filename and public class name match.
