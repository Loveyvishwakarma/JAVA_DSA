# Java Conditional Statements Questions ☕

A collection of Java programs for practising **conditional statements** and decision-making.

This repository is part of my Java and Data Structures & Algorithms (DSA) learning journey. The programs focus on using `if`, `if-else`, `else-if` ladders, and logical conditions to solve beginner-level problems.

## 📌 About This Repository

Conditional statements allow a program to make decisions and execute different blocks of code depending on whether a condition is true or false.

Through these exercises, I am practising how to:

- Use `if` and `if-else` statements.
- Apply `else-if` ladders for multiple conditions.
- Combine conditions using logical operators.
- Compare values using relational operators.
- Handle different input cases.
- Convert problem statements into decision-making logic.

## ▶️ How to Run a Program

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the repository folder

```bash
cd conditionalStatements
```

### 3. Compile a Java file

For example:

```bash
javac EvenOrOdd.java
```

### 4. Run the program

```bash
java EvenOrOdd
```

Replace `EvenOrOdd` with the class name of the program you want to execute.

**Note:** The Java filename and public class name must match. Make sure the Java JDK is installed and available in your terminal.
