# Java For Loop Questions ☕

A collection of Java programs for practising **`for` loops** and strengthening programming fundamentals.

This repository is part of my Java and Data Structures & Algorithms (DSA) learning journey. The programs focus on repetition, number operations, digit manipulation, and problem-solving using loops.

## 📌 About This Repository

Practising loop-based problems helps build a strong foundation in programming. Through these exercises, I am learning how to:

- Use `for` loops to repeat instructions.
- Control loop execution with conditions.
- Work with counters and accumulators.
- Perform calculations on numbers.
- Extract and process digits.
- Apply logic to solve beginner-level problems.

## ▶️ How to Run a Program

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the repository folder

```bash
cd forLoopQuestions
```

### 3. Compile a Java file

For example:

```bash
javac Factorial.java
```

### 4. Run the program

```bash
java Factorial
```

Replace `Factorial` with the class name of the program you want to execute.

**Note:** The Java filename and public class name must match. Make sure the Java JDK is installed and available in your terminal.
